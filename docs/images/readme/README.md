# README artwork

The README combines real Dwell UI with original editorial artwork. No additional rendering dependency is required by the application.

- **desktop.png** — a staged desktop composition, not an unmodified desktop screenshot. The app content is the real [Dwell capture](../dwell.png), with a demonstration project, placed over an original wallpaper. The menu bar, window controls, shadow and captions are composed for the presentation. The amber companion is rendered with the actual Eclipse shader.
- **workspace.png** — close-ups of the same application capture, with editorial typography.
- **eclipse-motion.gif** — the actual WebGL shader from [src/orb.js](../../../src/orb.js) at the time of Dwell 0.3.0, rendered in blue, amber and red. This six-second, 12 fps illustration uses a smooth forward-and-back time loop; it is not a recording or a performance measurement. Amber has twice the animation rate of blue. The app runs its animation continuously forward.
- **eclipse-still.png** — a static version for readers who prefer reduced motion. State descriptions also appear as selectable text in the README.

The wallpaper was generated with OpenAI's image generation tool on October 10, 2026. The application UI, text and Eclipse shapes were not generated by an image model. The original application capture remains available at [docs/images/dwell.png](../dwell.png).

## Wallpaper prompt

> Use case: ads-marketing. Asset type: original widescreen macOS desktop wallpaper for the Dwell terminal README. Create ONLY an exquisite abstract desktop wallpaper, no desktop UI, no computer hardware, no windows, no icons, no logos, no words. Landscape 16:10 composition, high resolution. A few monumental softly folded fluid surfaces, like light passing through smoked amber glass and warm silk. Rich burnt orange and copper across the lower left, luminous apricot and pale peach towards the upper right, a restrained dark burgundy shadow in one fold. Bold saturated warmth yet sophisticated and calm; premium industrial-design art direction, generous smooth fields, elegant curved diagonal contours, photographic material subtlety, extremely smooth gradients, tiny tactile grain. Avoid busy wisps, particle fields, stars, lens flares, excessive glowing effects, cartoon shapes, purple, blue. This backdrop will frame a graphite translucent application, so keep central detail quiet and the surrounding edges visually striking.
